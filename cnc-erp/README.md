# CNC 加工廠進銷存系統

> 第一次安裝、教同事使用：請先打開資料夾裡的 **`請先看我.html`**（點兩下就會用瀏覽器開，可以直接列印）。

給小型 CNC 加工廠用的輕量進銷存，目標是**讓老闆不用再自己記帳、追交期、算庫存**。

- 一台辦公室電腦裝 Python 就能跑，**不用買軟體、不用網路、不用月費**
- 工廠裡的電腦、手機、平板都可以用瀏覽器連線
- 所有資料在一個檔案 `cnc.db`，複製一份就是備份

## 系統能做什麼

| 功能 | 說明 |
|---|---|
| **今日總覽** | 一打開就看到：逾期訂單、7 天內要交的貨、進行中工單、要補貨的材料、應收/應付帳款、本月出貨金額 |
| **銷貨訂單** | 客戶下單 → 記錄交期、客戶單號/圖號 → 可分批出貨（自動扣庫存）→ 登記收款 → 列印出貨單 |
| **生產工單** | 由訂單直接開工單，設定機台、每件用料；完工回報良品/不良品數，**自動扣原料、成品入庫** |
| **採購進貨** | 向材料行下採購單 → 到貨時按「確認進貨」自動加庫存，並更新最新進價 → 登記付款 |
| **庫存品項** | 原料、成品、刀具、耗材分類管理；低於安全庫存會標紅提醒；可直接盤點調整 |
| **庫存異動** | 每一筆進出都有紀錄（進貨、出貨、領料、完工、盤點），查得到是哪張單造成的 |
| **客戶/廠商** | 聯絡人、電話、統編、付款條件備註；點進去看**這家客戶的完整往來紀錄**：往來期間、累計金額、每年金額、常訂品項與最近單價 |
| **歷史查詢** | 打料號、品名或客戶就查得到「這個零件以前賣給誰、賣多少錢」，舊系統紀錄和新訂單一起查 |
| **報價** | 收到圖面拍照建檔、估價（材料 + 工時 + 架機 + 外包 + 利潤）、列印報價單、成交一鍵轉訂單 |
| **排程 / 現場報工** | 製程路線、機台佇列、自動估完工日與延誤警示、手機報工、外包追蹤 |
| **設定/匯入** | 公司資料、工時費率、登入密碼、機台；從凌越匯入；一鍵備份（含圖面）；匯出庫存表 |

## 為 CNC 加工廠設計的地方

- **品項有客戶圖號、版次、材質、表面 / 熱處理、所屬客戶、單件工時**：材質和處理方式有常用選項可以直接點；
  用圖號也搜得到零件。
- **開單打字就能找料號**：輸入料號、品名或圖號就會跳出符合的品項，選了客戶會自動帶入這家客戶上次的價格。
- **總覽**：本月 / 今年累計銷貨並和去年比較、近 12 個月銷貨圖、前十大客戶與占比（過度集中會提醒）、
  **久未下單的老客戶**（該打電話了）、**常回單的零件**（可先備料）、**機台負荷**（依單件工時估算每台機器還要做幾小時）。
- **客戶 / 廠商分兩頁**，可依最近往來、今年 / 去年 / 累計金額排序；可以自訂分類（例：A級客戶、外包熱處理），
  勾選多家一次設定，也能一次把勾選的改為客戶或供應商。
- **公司登記資料**：用統一編號向經濟部商工登記公示資料查詢公司名稱、負責人、地址、資本額、登記狀態，
  若對方已歇業 / 解散會標紅提醒。需要網路；查不到時會附上經濟部查詢網站連結。

## 從接單到出貨的完整流程

```
收到圖面（手機拍照 / LINE 存圖 / PDF / CAD）
   │  報價 →「收到圖面：新增詢價」：選客戶、拍照上傳，外面就能先建檔
   ▼
估價：材料費 + 加工工時 + 架機時間（依數量分攤）+ 外包費 → 加利潤 → 建議單價
   │  同圖號以前的報價 / 成交價會自動列出來參考 → 列印報價單
   ▼
客戶確認 →「成交 → 轉訂單」：自動建立客戶、零件（圖面跟著掛到零件上）與銷貨訂單
   ▼
開工單：自動帶入零件的「製程路線」（例：CNC 車床 → 熱處理（外包）→ 研磨 → 檢驗）
   ▼
排程看板：每台機台的工作佇列，依工時、每天可用時數、前後工序自動估完工日；
          會延誤的標紅，可以往前排或換機台
   ▼
現場報工（手機 / 平板）：選機台 → 看圖面 → 按「開始」「報工」；外包「送出」「回廠」
   ▼
工序全部完成 → 完工入庫（自動扣料、成品入庫）→ 出貨 → 收款
```

### 報價與圖面歸檔
- 詢價可以依**客戶、分類（車床件、銑床件…）、狀態（待報價 / 已報價 / 成交 / 未成交）**篩選，
  也能用圖號、品名、材質搜尋；每張報價都看得到縮圖。
- 未成交可以記錄原因（價格、交期…），總覽會顯示近半年成交率。
- 圖面、照片、PDF、CAD 檔都可以上傳；手機照片會自動縮小（長邊 2400px，圖面仍清楚）。
- 附件存在 `files` 資料夾；「下載備份檔」會把資料庫和所有圖面一起打包成 zip。

### 生產排程
- 「排程 → 機台設定」：建立機台與每天可用時數（兩班制填 16）。
- 品項詳細資料 →「製程路線」：設定一次，之後開工單自動帶入。熱處理、表面處理等可勾「外包」並指定廠商與天數。
- 「設定」可以調整工作日（預設週一到週六）與工時費率。

### 在外面用手機
1. 先建立管理員帳號，並在「設定 → 使用者帳號」幫要用手機的人各開一個帳號。
2. 系統電腦和手機都安裝 [Tailscale](https://tailscale.com/)（見「做法 B」第 7 步）。
3. 手機瀏覽器開 `http://系統電腦的 Tailscale 位址:8080`，用自己的帳號登入，選「加入主畫面」就像 App 一樣使用。
4. 在外面收到 LINE 圖面：先存到相簿 → 打開系統 → 報價 → 新增詢價 → 選照片。

## 單據列印

| 單據 | 在哪裡印 |
|---|---|
| **出貨單 / 進貨驗收單** | 訂單按「確認出貨 / 進貨」後會問要不要印；每次出貨（可分批）各有一個單號（SH- / RC-），之後在「單據列印」可以搜尋補印、勾選多張一起印 |
| **訂單確認單 / 採購單** | 訂單視窗 →「列印」 |
| **報價單** | 報價頁 →「列印報價單」 |
| **工單製程卡** | 工單視窗 →「列印製程卡」：工序、機台、標準工時、作業員 / 檢驗簽名欄，附第一張圖面，跟著零件走 |
| **外包加工單** | 工單視窗或排程看板的外包工序 →「外包單」：送熱處理、電鍍時交給廠商 |
| **月結對帳單** | 客戶頁 →「對帳單」，或「單據列印 → 月結對帳單」一次印出所有客戶：上期未結 + 本期出貨（含稅）− 本期收款 = 本期應收 |

- 單據上會印公司名稱、地址、電話、統編、匯款資訊（在「設定」填寫），金額附新台幣大寫。
- **營業稅**：每張訂單可選外加 5% / 內含 / 免稅（預設值與稅率在「設定」）；單據自動列出未稅、稅額、合計，
  應收帳款也以含稅金額計算。（升級前就存在的舊訂單維持免稅，金額不會變。）
- **紙張**：A4 直式 / 橫式、A5、**中一刀（9.5×5.5 吋連續報表紙）**，在「設定」選。
- **一式多聯**：在「設定」填例如「第一聯 客戶聯,第二聯 存根聯」，每張單會依序各印一張並標上聯別。

## 資料安全與備援（商業使用必讀）

客戶圖面、報價、往來紀錄都是機密，請照下面設定：

### 1. 帳號與存取
- **每個人一個帳號，不要共用**。第一次打開系統會要求建立「管理員」帳號（通常是老闆），
  之後由管理員在「設定 → 使用者帳號」幫其他人開帳號、設定角色：

  | 角色 | 能用的功能 |
  |---|---|
  | **管理員** | 全部，包含使用者帳號、系統設定、備份、從凌越匯入、存取紀錄 |
  | **辦公室人員**（主管、業務、會計） | 總覽、報價、訂單、採購、庫存、客戶 / 廠商、排程、單據列印、歷史查詢 |
  | **現場人員** | 只有「現場報工」「排程」與看圖面；看不到價格、金額、客戶往來 |

- 存取紀錄會記下**誰**新增訂單、出貨、改報價、改客戶資料、登入 / 登入失敗、下載備份。
- 有人離職：把他的帳號「停用」，他所有裝置立即登出、不能再登入，其他人不受影響。
- 每個人點右上角自己的名字可以改密碼、登出。管理員忘記密碼：在系統電腦執行 `python server.py --reset-admin` 取得臨時密碼。
- 還沒建立帳號前，只有系統電腦本身能用；其他電腦 / 手機連線時會被要求先建立管理員帳號，看不到任何資料。
- 同一個 IP 連續輸錯 5 次密碼，鎖 10 分鐘。
- 「設定 → 存取紀錄」查得到誰、從哪個 IP、什麼時候做了什麼。看到不認識的 IP 或大量登入失敗，請立即停用該帳號或換密碼。
- **在外面使用只走 Tailscale**（私人加密連線），**不要在路由器開 port、不要用 DDNS / QuickConnect 把系統公開到網路上。**

### 2. 雙備援（3-2-1 原則：3 份資料、2 種儲存設備、1 份異地）
| 份 | 放哪裡 | 怎麼做 |
|---|---|---|
| 1 | 正在使用的資料庫 | 系統所在的電腦或 NAS |
| 2 | **備份位置 1：NAS** | 「設定 → 自動備份」填 NAS 資料夾，每天自動備份並驗證可還原 |
| 3 | **備份位置 2：另一個設備** | 外接硬碟或另一顆硬碟；系統每天同時寫一份 |
| ＋ | **異地 / 加密** | 在 NAS 用 **Hyper Backup** 把備份資料夾**加密**備份到外接硬碟或 Synology C2（雲端），開啟版本保留 |

- 每份備份寫完都會自動驗證（壓縮檔完整、資料庫能開、完整性檢查通過）；失敗會顯示在「設定」並寫入存取紀錄。
- 一個位置故障（例如 NAS 沒開）不影響另一個位置繼續備份。
- 每季至少做一次**還原演練**：拿一份備份在另一台電腦解壓縮、用 `demo.bat` 的方式開起來確認資料正確。
- NAS 上放備份的共用資料夾，權限只開給老闆 / 管理者帳號；建議開啟 NAS 的資料夾加密。

### 3. 資料庫放在哪裡
- ❌ **不要**讓電腦上的系統直接讀寫放在 NAS 網路磁碟（`\\NAS\...`）上的資料庫，網路中斷或多人同時寫入時容易損毀。系統偵測到會在啟動時警告。
- ✅ 做法 A：系統裝在**辦公室電腦**（資料在本機），每天自動備份到 NAS + 外接硬碟。
- ✅ 做法 B：系統直接**裝在 NAS 上**（見下一節），電腦不用一直開機；再用 Hyper Backup 做第二、第三份。

## 正式上線：做法 B 一步一步（系統在辦公室電腦、每天備份到 NAS）

1. **選一台當系統主機的辦公室電腦**（白天都會開著的那台），把 `cnc-erp` 資料夾放在它的本機硬碟，例如 `D:\cnc-erp`（不要放在 NAS 上）。
2. 雙擊 **`install-autostart.bat`**：設定開機自動啟動、在桌面建立「CNC 進銷存」捷徑，並立刻在背景啟動系統。
   - 工作列會有一個縮小的「CNC 進銷存（背景執行中）」視窗，**不要關掉它**。
   - 系統意外停止會在 5 秒後自動重啟。之後雙擊 `start.bat` 或桌面捷徑，只會打開瀏覽器，不會重複開。
   - 不想自動啟動時，雙擊 `uninstall-autostart.bat`。
3. **電源設定**：Windows 設定 → 系統 → 電源 →「睡眠」改為「永不」（螢幕可以關）。電腦睡著時手機連不到、也不會備份。
4. **讓電腦記住 NAS 帳密**：在檔案總管網址列輸入 `\\NAS名稱`，登入時勾選「記住我的認證」。這樣背景備份才寫得進 NAS。
5. 打開系統：第一次會要求**建立管理員帳號**。接著到「設定」：
   - 「使用者帳號」幫每位主管 / 同事建立自己的帳號。
   - 「自動備份」位置 1 填 NAS 資料夾（例：`\\NAS名稱\homes\公司共用\資料夾\系統備份`，先在 NAS 建好這個資料夾），
     位置 2 填外接硬碟或另一顆硬碟（例：`E:\系統備份`）→ 按「**立即備份並驗證**」，兩個都要顯示「正常」。
6. 在 NAS 用 **Hyper Backup** 把「系統備份」資料夾加密備份到外接硬碟或雲端（第三份、異地）。
7. 在外面用：系統電腦和每位主管的手機都安裝 **Tailscale**。系統電腦用公司的 Tailscale 帳號登入，
   再從 Tailscale 管理頁邀請主管加入，或把這台電腦「分享」給他們（官方免費方案目前可 6 位使用者；
   商業用途請到 Tailscale 官網確認方案與條款）。

之後每天打開「總覽」，如果備份有問題，最上方會出現紅色提醒（沒設定、只設一處、失敗、超過 2 天沒成功）。

## 把系統裝在 Synology NAS 上（Container Manager）

適用有「Container Manager」（舊名 Docker）套件的 Synology 機型（多數 + 系列、x86 機型）。

1. 套件中心安裝 **Container Manager**。
2. 把整個 `cnc-erp` 資料夾複製到 NAS，例如 `/docker/cnc-erp`（共用資料夾權限只給管理者）。
3. Container Manager →「專案」→「新增」→ 路徑選 `cnc-erp` 資料夾 → 使用資料夾裡的 `docker-compose.yml` → 建立。
4. 瀏覽器開 `http://NAS的IP:8080`，第一次會要求**設定密碼**。
5. 資料庫與圖面存在 `cnc-erp/data` 資料夾裡（就是 NAS 上的實體資料夾）。把這個資料夾加進 **Hyper Backup**。
6. 外面使用：套件中心安裝 **Tailscale**，手機也裝 Tailscale，用 `http://NAS的Tailscale位址:8080` 連線。
7. 要從舊電腦搬過來：先停掉電腦上的系統，把 `cnc.db` 和 `files` 資料夾複製到 NAS 的 `cnc-erp/data` 裡，再啟動專案。

容器內使用台灣時區；NAS 重開機後系統會自動啟動。

## 安裝（第一次，約 5 分鐘）

1. 把整個 `cnc-erp` 資料夾複製到辦公室電腦的本機硬碟，例如 `D:\cnc-erp`。
2. **電腦沒有 Python 的話，雙擊 `install-python.bat`**：會用 Windows 內建的 winget 自動安裝 Python 3.12（約 1~3 分鐘）。
   裝完**關掉視窗**再進行下一步。
   - 如果自動安裝失敗，它會打開 Python 官網：下載 Windows installer 執行，**第一個畫面最下面「Add python.exe to PATH」要打勾**，再按 Install Now。
   - 系統支援 Python 3.7 以上任何版本。
3. 先試玩：雙擊 `demo.bat`（獨立的示範資料）。正式使用：照上面「做法 B 一步一步」。

## 每天使用

- **雙擊 `start.bat`**：系統啟動並自動開啟瀏覽器。黑色視窗不要關（關掉系統就停了）。
- 想先試玩：雙擊 `demo.bat`，會用一份**獨立的示範資料**（`demo.db`），不會影響正式資料。

### 讓其他電腦 / 手機連線

`start.bat` 已開放區網連線。在跑系統的電腦上打開「命令提示字元」輸入 `ipconfig`，
找到「IPv4 位址」（例如 `192.168.1.20`），其他裝置的瀏覽器輸入 `http://192.168.1.20:8080` 即可。
第一次啟動時如果 Windows 防火牆跳出詢問，請按「允許」。

> ⚠️ 這個版本沒有帳號密碼，只適合在工廠內部網路使用，**不要**把 8080 port 開到外網。

## 從凌越轉移資料（建議做法）

凌越不能匯出 Excel 也沒關係：它的「備份」功能產生的 `wstkBKUP.001` 就能直接轉。

1. 在凌越做一次備份（會得到 `wstkBKUP.001`）。
2. 新系統「設定/匯入」頁 →「從凌越備份檔一次轉入」：選擇這個檔案，或直接輸入位置（例如 `\\NAS名稱\homes\公司共用\資料夾\wstkBKUP.001`）。
3. 畫面會列出凌越裡的**單據種類**和**客戶 / 廠商類別**，系統已先猜好（依往來對象和售價 / 成本判斷），
   看一下「最常往來」的名字對不對，不確定的單據種類選「不匯入」。
4. 按「開始轉入」。會轉進：客戶與廠商（含統編、電話、地址、傳真、聯絡人、凌越裡的備註）、
   產品 / 材料（含規格、單位、成本、售價、儲位、**當時的庫存數量**、安全存量）、所有過去的進銷貨明細（退貨記為負數）。
5. 凌越裡還沒結案的訂單會列出來，請在新系統重開。

可以重複轉：同一份資料不會重複，產品和客戶資料會更新成最新的。所以正式切換那天，在凌越再備份一次、再轉一次即可。
技術細節見 `lingyue.py`：備份檔是多個 Visual FoxPro 資料表（`.DBF` + `.FPT` 備註）串在一起，主要用到 `CUST`、`STOCK`、`SLIP`、`SLIPDT`、`ORDER`。

## 從其他舊系統（Excel / CSV）轉移資料

到「設定/匯入」頁，用「從舊系統匯入」功能，一次匯入一種資料：

| 在舊系統匯出這些 | 匯入時選 |
|---|---|
| 產品 / 材料資料，**最好是含目前庫存量的庫存表** | 產品 / 材料（含庫存） |
| 客戶資料 | 客戶 |
| 廠商資料 | 供應商 |
| **銷貨明細表**（越多年越好） | 過去的銷貨紀錄（客戶歷史） |
| 進貨明細表 | 過去的進貨紀錄 |

- 支援 **.xlsx、.csv（Big5 / UTF-8）、.dbf**。舊版 `.xls` 先用 Excel「另存新檔」成 `.xlsx`。
- 系統會自動找表頭（報表上方的公司名稱、列印日期會略過）並辨識「產品編號、品名、庫存量、平均成本…」等常見欄位；
  辨識不到的欄位可以在畫面上手動選。**先預覽，按確認才寫入**。
- 同一個料號（或同名客戶 / 廠商）再匯入一次只會更新，不會重複。庫存會設成檔案中的數字，並在異動紀錄留下「舊系統轉入」。
- **過去的交易紀錄**永久保存在新系統，只供查詢、不影響庫存。民國年日期（113/03/05、1130305）看得懂；
  報表中「同一張單只有第一行印單號、日期、客戶」的格式會自動往下沿用；小計 / 合計列自動略過；
  同一份檔案重複匯入不會重複。紀錄裡出現、但客戶清單沒有的客戶會自動建立，**舊客戶不會遺失**。
- 開新訂單選了客戶和品項後，系統會自動帶入**這個客戶上次的成交價**，並列出最近幾次的價格。

**建議做法**：選一天下班後，在舊系統印出 / 匯出當天的庫存表 → 匯入 → 隔天開始只用新系統開單。
進行中的訂單建議手動在新系統重開（通常不多）。過去的銷貨 / 進貨明細表能匯出幾年就匯幾年，之後就算舊系統的電腦壞了，客戶往來紀錄也都還在。

## 導入計畫（給老闆們）

| 階段 | 時間 | 做什麼 | 誰 |
|---|---|---|---|
| **1. 安裝** | 半天 | 照「做法 B 一步一步」裝好、建立管理員、設定公司資料與兩個備份位置、從凌越轉入資料 | 負責維護的人 |
| **2. 試行** | 2～4 週 | **凌越照常用**，新系統平行跑：先由一位主管用報價、查歷史價格、看總覽；挑幾張訂單同時在兩邊開，比對數字 | 1～2 位主管 |
| **3. 教育訓練** | 1 週 | 每人開自己的帳號；用 `demo.bat` 的示範資料練習（不會弄亂正式資料）；現場師傅練習用手機報工 | 全體 |
| **4. 正式切換** | 選一個月初 | 前一天下班後：凌越最後一次備份 → 新系統「從凌越轉入」再跑一次（只會補新資料，不會重複）→ 盤點一次庫存；隔天起只用新系統開單 | 全體 |
| **5. 穩定運作** | 之後 | 每天看「總覽」的備份提醒；每月印對帳單；每季做一次還原演練；需要新功能由維護的人用 Claude Code 修改 | 管理員 |

切換後凌越的電腦與資料**至少保留一年**，隨時可以回頭查。

## 一張訂單的流程

```
客戶下單 ─▶ 銷貨訂單 ─▶ 開工單（設定機台、每件用料）
                              │
                    開始生產 ─▶ 完工回報（良品 / 不良）
                              │   → 原料自動扣除、成品自動入庫
                              ▼
                     訂單「確認出貨」→ 成品扣庫存、列印出貨單
                              ▼
                        登記收款 → 應收帳款自動減少
```

**每件用料怎麼填？** 例如一支 3 米鋁棒可以車 60 個軸，每件用量就填 `1/60 ≈ 0.0167`（支）。
完工時系統會用「(良品 + 不良品) × 每件用量」扣原料。

## 備份與還原

- **備份**：「設定/匯入」頁按「下載備份檔」，會得到一個 zip（資料庫 `cnc.db` + 圖面 `files` 資料夾）。建議每天下班前做一次，存到隨身碟、NAS 或雲端硬碟。
- **還原**：關閉系統 → 解壓縮，把 `cnc.db` 和 `files` 放回程式資料夾 → 重新啟動。

## 更新系統

- **用 git 下載的（建議）**：在系統電腦雙擊 **`update.bat`**。它會：
  1. 先把資料庫和圖面存一份快照到 `pre-update\`；
  2. 下載最新版程式；
  3. 跑完整測試，**沒通過就自動退回舊版**，系統照常使用；
  4. 通過才重新啟動系統。客戶資料（`cnc.db`、`files\`）不會被更新動到。
- **用 zip 下載的**：先在「設定」按「立即備份並驗證」→ 關掉系統視窗 → 把新版 zip 裡的程式檔案複製過來覆蓋
  （**不要**刪掉或覆蓋 `cnc.db`、`files` 資料夾）→ 重新開系統。
- 目前版本在「設定 → 系統資訊」；每版改了什麼見 `CHANGELOG.md`。

## 給維護的人（用 Claude Code 自己維護）

1. 安裝 git 與 Claude Code，把程式庫 clone 到工廠系統電腦（或自己的電腦）。
2. 在 `cnc-erp` 資料夾開 Claude Code。它會先讀 **`CLAUDE.md`**（系統架構與必須遵守的規則：只用標準函式庫、
   資料庫只能加不能改、新 API 要設權限、不能把客戶資料放進 git…）。
3. 用白話描述需求，例如「出貨單上加一欄客戶料號」「總覽加一張本月各機台稼動率」。
4. 請 Claude 改完**跑全部測試**（`test.bat` 或 `python -m unittest discover -p "test_*.py"`），並用示範資料開起來看畫面：
   `set CNC_DB=%TEMP%\demo.db` 再 `python server.py --demo`（不碰正式資料）。
5. 測試全過再 commit、push；工廠電腦雙擊 `update.bat` 套用。
6. `.claude/settings.json` 已設定：Claude 可以直接跑測試；**不能讀取**資料庫、圖面、備份檔（客戶機密不會送到 AI）。

技術細節：
- 後端：`server.py`、`accounts.py`、`quotes.py`、`production.py`、`documents.py`、`importer.py`、`lingyue.py`，只用 Python 標準函式庫（3.7 以上）。
- 前端：`static/` 裡的原生 HTML / JS / CSS，不需要編譯。
- 庫存不直接存數字，而是由 `stock_moves` 異動紀錄加總，所以任何數字都可追溯。
- 指令參數：`python server.py --port 8080 --lan --demo`、`--snapshot`（快照備份）、`--reset-admin`（重設管理員密碼）；環境變數 `CNC_DB` 指定資料庫位置。
