CNC 進銷存系統：開始使用

報價、訂單、出貨、庫存、生產排程、單據列印。系統裝在公司一台電腦上，其他人用瀏覽器或手機連線使用，不用每台都安裝。

一、安裝（只要做一次）負責的人

選一台白天都會開機的辦公室電腦（Windows 10 / 11）。

  1. 解壓縮：在 zip 檔上按右鍵 →「內容」→ 勾選右下角「解除封鎖」→ 確定（之後執行比較不會被 Windows 擋）。 再按右鍵 →「解壓縮全部」，放到本機硬碟，例如 D:\cnc-erp。
    不要放在 NAS 或隨身碟上執行；也不要直接在 zip 裡面點兩下。
  2. 安裝 Python（系統需要它）：雙擊 install-python.bat，等 1～3 分鐘，看到「安裝完成」就關掉視窗。
    電腦已經有 Python 會直接告訴你，可以跳過。
  3. 設定開機自動執行：雙擊 install-autostart.bat。完成後：
    • 工作列會多一個縮小的「CNC 進銷存（背景執行中）」視窗：不要關掉它。
    • 桌面會多一個「CNC 進銷存」捷徑。
    • 如果 Windows 防火牆詢問，請按「允許」（其他電腦、手機才連得到）。
  4. 電源設定：Windows「設定 → 系統 → 電源」，把「睡眠」改成「永不」（螢幕可以關）。
  5. 建立管理員帳號：點桌面捷徑打開系統，第一次會要求建立管理員（通常是老闆）的帳號與密碼。
⚠️ 看到藍色視窗「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。這是 Windows 對網路下載檔案的一般提醒。

二、第一次設定管理員

打開系統 → 上方選單「設定/匯入」：

  1. 公司資料：公司名稱、統編、電話、地址、匯款帳號（印在所有單據上）；「系統上方顯示的名稱」可填簡稱。
  2. 使用者帳號：幫每個人開一個帳號（不要共用）。
    角色適合誰能用的功能
    管理員老闆全部，含帳號、設定、備份
    辦公室人員主管、業務、會計報價、訂單、採購、庫存、客戶、排程、單據
    現場人員師傅只有現場報工、排程、看圖面（看不到價格）
  3. 自動備份：位置 1 填 NAS 資料夾、位置 2 填外接硬碟（例 E:\系統備份），按「立即備份並驗證」，兩個都要顯示「正常」。
    NAS 要先在檔案總管登入一次並勾「記住我的認證」。
  4. 從凌越轉入資料：在凌越做一次備份，把 wstkBKUP.001 交給「從凌越備份檔一次轉入」，確認後按「開始轉入」。
  5. 機台：「排程 → 機台設定」建立你們的機台與每天可用時數。

三、其他人怎麼用所有人

在哪裡怎麼開
系統那台電腦點桌面「CNC 進銷存」
公司內其他電腦 / 手機（同一個 Wi-Fi）瀏覽器輸入 http://系統電腦的IP:8080
IP 查法：在系統電腦按「開始」輸入 cmd → 輸入 ipconfig → 看「IPv4 位址」，例如 192.168.1.20
在外面用手機系統電腦和手機都安裝 Tailscale，手機開 http://系統電腦的Tailscale位址:8080
不要在路由器開 port 把系統公開到網路上。

用自己的帳號登入；手機可在瀏覽器選「加入主畫面」，以後像 App 一樣點開。忘記密碼請找管理員重設。

四、建議的導入方式

  1. 試行 2～4 週：凌越照常用，新系統平行跑，先由一位主管用報價、查歷史價格、看總覽。
  2. 教育訓練：每人用自己的帳號，雙擊 demo.bat 用示範資料練習（不會弄亂正式資料；練習前先關掉正式系統的視窗）。
  3. 正式切換：選一個月初，前一晚凌越最後備份一次 → 新系統再轉入一次 → 盤點庫存；隔天起只用新系統開單。凌越資料至少保留一年。

五、每天 / 每月要注意

  • 每天打開「總覽」：最上方如果出現紅色「備份需要注意」，請管理員處理。
  • 列印單據時，列印視窗的「頁首和頁尾」取消勾選（不然紙上會多印網址）。
  • 每月：「單據列印 → 月結對帳單」。
  • 更新新版：維護的人會告訴你；用 git 安裝的雙擊 update.bat（自動備份、檢查，失敗自動退回）。

遇到問題

打不開網頁看系統電腦工作列上的「CNC 進銷存」視窗還在不在；不在就點兩下桌面捷徑旁的 start.bat。
其他電腦連不到確認在同一個網路、IP 打對、防火牆有允許；系統電腦不能睡眠。
管理員忘記密碼在系統電腦的程式資料夾，網址列輸入 cmd 按 Enter，再輸入 python server.py --reset-admin，會顯示臨時密碼。
其他問題把畫面拍照給負責維護的人。詳細說明在資料夾裡的 README.md。

客戶資料只存在你們自己的電腦（cnc.db 與 files 資料夾）與你們設定的備份位置，不會上傳到任何雲端。
